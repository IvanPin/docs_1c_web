# Проверка пакета сертификатов — 05.11.2026

Проверен перенесённый пакет этого репозитория, API **1.0.0**.

- **41 проверка** происхождения/совпадения исходников, PHP-синтаксиса и локального HTTP-обмена прошла.
- **22 проверки** схем и встроенных примеров OpenAPI через AJV прошли.
- **13 отдельных JSON-примеров** запросов и ответов соответствуют схемам OpenAPI.
- Относительные ссылки в новых документах проверены.

HTTP-стенд запущен только на `127.0.0.1` с временным состоянием и открытым тестовым ключом. Проверены два оплаченных заказа, страницы очереди, повтор подтверждения, несовпадающая сумма, смена/повторное использование номера, неоплаченный/отменённый заказ, ошибки доступа и пагинации. Сценарии клиента `unavailable` и `wrong-amount` сохранили заявки; `lost-response` вернул `seen: 2`, `accepted: 2`, `replayed: 2`, `errors: []`; следующий проход вернул пустую очередь. Сервер остановлен, временные данные удалены.

Сценарий `lost-response` повторяет POST после полученного успешного ответа. Аварийное завершение настоящей 1С и устойчивость её хранения не проверялись; это отдельные критерии совместной приёмки.

Дополнительная проверка `postman spec lint` не выполнена: CLI получил HTTP 403 при загрузке feature flags и завершился с `Unable to retrieve governance rulesets`. Установленная версия CLI также не поддерживает `postman status`. Валидация схем и примеров выполнена локально через AJV; успешная проверка Postman не заявляется.

Настоящие 1С, Битрикс/MySQL, Робокасса, SMTP и DEV/production в этой проверке не использовались. Исторические проверки Битрикса от 29.10.2026 описаны в контракте отдельно. Документация и локальная проверка не означают готовность production-продаж.
