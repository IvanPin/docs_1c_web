На стороне сайта подготовлена реализация, ранее проверенная с моками. Реальная 1С и совместная приёмка ещё требуются; публикация backend сертификатов на DEV/production не подтверждена, продажи выключены. Текущий этап — [PIN-557](https://ponama.atlassian.net/browse/PIN-557). Баланс в личном кабинете и применение при оплате относятся к следующим этапам и не входят в API 1.0.0.
